# bnu434 说明

## 真题分析

- 工具 `zhenti_analyze` / `zhenti_report` / `zhenti_tag`；
- 报告：`report.html`（离线可开），设置页 **设置 → BNU434 真题与模拟题** 有热力面板；
- 数据范围：2022—2026 现行版式 60 个设问；2020—2021 旧版式只进考点年表。

## 模拟题命题

- 工具 `zhenti_mock`：按真题章权重随机生成命题蓝图（题型、分值、章、候选考点、冷门位、热点位），并附封装提示词；
- 把蓝图与提示词交给当前模型，即可生成完整试卷与参考答案，体例为「题目＋参考答案＋考点分析＋答题思路」；
- 支持 `seed` 复现、指定名解/简答/论述题量；
- 生成内容由模型产出，发布给学生前请人工核对。

## 知识点库

- 考纲知识点（核心必背、次重点、了解即可三个层级），每条四段：定义、提纲、要点、真题考法；
- 工具 `zhenti_search` 可按关键词、考纲章、层级检索；
- 内容加密为 `knowledge.enc`（AES-256-GCM，统一密钥），运行时解密；属于轻度保护，不是强版权保护；
- 不预置任何模拟试卷。

## 内容说明

- 知识点笔记、考点分析、参考答案与模拟题均为 AI 辅助整理或生成，可能存在偏差，仅供学习参考；
- 请以教材与官方考纲为准，发现错误欢迎反馈。

## 数据与限制

- 默认数据目录 `~/.dsh/bnu434-data`，首次运行自动初始化；
- 数据只含题干摘要与考点标注，不含教材原文与真题全文；
- 统计与候补排序是描述性分析，不是押题；
- 不联网，全部本地运行。
