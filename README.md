## 这是什么

一个装在 DeepSeek Harness（DSH）里的本地插件。装好后刷新页面，左上角会出现 **BNU434 真题** 入口，点开即可使用。

它不做“押题”，只做三件事：

1. 把 2020—2026 真题整理成可计算的数据，告诉你看得见的规律；
2. 把 370 条 ★ 知识点做成能抽背、能检索的资料库；
3. 随机出模拟题：离线秒出要点版答案，在线调用你自己的模型写完整答案。

统计与候补排序都是描述性分析，**不是押题**；请按考纲全面复习。

---

## 功能

### 真题分析

- 考纲 15 章五年分值热力表、题型结构、模块占比；
- 考点族频次、轮考间隔、重复率（70%）、2027 候补排序；
- **按年份查看 2020—2026 真题与答案**：选择题型、展开看参考答案、考点分析、答题思路；
- 默认停在 2022 年（现行版式起点），可切换到 2020/2021 旧版式；
- 完整报告导出为离线 HTML。

### 抽背模式（离线）

- 按章多选、设题量、随机抽知识点；
- 先只出题，点「显示答案」再看资料库要点；
- 「记住了 / 没记住」记在本机，方便下一轮重点复习；
- 零成本、秒出、不联网。

### 模考模式

- **离线要点版**：随机出一整卷（4 名解＋4 简答＋2 论述，150 分），答案直接来自资料库；
- **在线 AI 完整版**：随机抽题＋内置热点素材，套用封装提示词，调用你 DSH 当前配置的模型，生成完整试卷与参考答案；
- 生成中**只显示题目、不显示答案**，避免影响模考；
- 完成后逐题折叠，点开才看答案；支持导出 Markdown、保存到本地。

### 资料库

- 370 条 ★ 知识点，按章筛选、关键词搜索；
- 每条含定义、提纲、要点、真题考法；
- 可展开、可复制，内容加密存储、运行时解密。

## 安装

前提：已安装 DeepSeek Harness（DSH）桌面版或 Web 版。

1. 打开 DSH 的插件页 **Plugins → Add plugin**；
2. 输入包名 `bnu434`，按提示安装；
3. 刷新页面（F5）；
4. 左上角侧边栏出现 **BNU434 真题**，点击即可打开面板。

也可以让 Agent 调用插件管理器安装：

```text
install_bundle target = bnu434
```

本地开发时，target 传本仓库目录的绝对路径即可。

## 使用

| 标签 | 用途 |
|---|---|
| **真题分析** | 看热力与候补 → 按年份翻真题与答案 |
| **抽背模式** | 碎片时间过知识点，先出题后看答案 |
| **模考模式** | 离线要点卷／在线 AI 完整卷 |
| **资料库** | 搜、筛、看、复制 370 条 ★ 笔记 |
| **说明** | 使用说明、数据范围、更新与留言 |

### 关于在线 AI

- 使用你 DSH 当前配置的模型，不需要额外填 API Key；
- 每套约 1—2 万 tokens（约 ¥0.01—0.05），通常 1—5 分钟；
- 后台生成，可以切到抽背、资料库或工作区继续用，回来接着看；
- AI 内容仅供练习参考，正式背诵请以教材表述为准。

## 项目结构

```text
bnu434/
├── index.js          # Host 半：工具、面板数据接口、AI 任务
├── client.js         # 浏览器半：左上角入口与五个标签页面板
├── analyzer.js       # 真题分析内核（纯 JavaScript）
├── drill.js          # 抽背/模考出题、AI 提示词、AI 逐题解析
├── knowledge.js      # 知识库加载与检索（支持加密文件）
├── mock.js           # 命题蓝图（进阶工具用）
├── crypto.js         # 本地内容读取
├── core/data/        # 随包数据：真题、知识点、热点、加密后的笔记与答案
├── prompts/          # 封装提示词
├── locale/           # 中英文文案
└── docs/DETAIL.md    # 插件详情页
```

数据目录（首次运行自动初始化）：

```text
~/.dsh/bnu434-data/
├── data/             # 真题、知识点、热点、加密内容
├── metrics.json      # 分析指标
├── report.html       # 真题分析报告
└── exports/          # 面板里导出的 Markdown
```
